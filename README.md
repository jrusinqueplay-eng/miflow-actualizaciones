# JR Suite AI — actualizaciones

Este repositorio solo sirve para que las copias instaladas de **JR Suite AI** se mantengan al día:

- `miflow.json`: configuración remota (textos de la web de Flow por idioma, avisos y la última versión disponible).
- `miflow.json.sig`: firma Ed25519 de `miflow.json`. JR Suite AI ignora cualquier configuración cuya firma no sea válida.
- **Releases**: cada versión de `JRSuiteAI.exe`. JR Suite AI comprueba su SHA-256 antes de instalarla.

No contiene datos de ningún usuario.
